# Architecture Explorer model

The explorer represents domains, nodes, typed relationships, connected paths, scenarios, selection, highlighting, explanations, and animation-ready state. Cross-cutting domains are explicit rather than inferred from display position.

`enterprise-ai-example.ts` provides one conceptual enterprise AI architecture with relational data spanning business outcome, experience, applications, AI intelligence, RAG, agents, models, enterprise data, integration, governance, and operations. It is sample architecture data, not learning content or a prescribed production design.

Future visualization components will derive nodes, edges, selected paths, and scenario transitions from this model. Rendering coordinates and animation implementation remain view concerns.
